# 会记 HTML Demo 设计说明

## 目标

交付一个可以直接双击打开、无需安装依赖或联网的中文桌面风格 HTML Demo。它演示“会记”的核心体验：开始/停止会议录音、模拟实时逐字稿、基于逐字稿生成结构化会议纪要、编辑逐字稿后重新生成，以及导出 Markdown。

## 使用者与成功标准

面向会议主持人或项目经理。打开页面后，用户应在一分钟内看懂录音状态、逐字稿、纪要、行动项与导出路径，并能完成一次可见的端到端演示。

## 范围

- 单一 `index.html`，内嵌 CSS、SVG 和经典 JavaScript；不使用 CDN、构建工具、框架或网络请求。
- 采用已确认的技术极简视觉：浅色纸张底、森林绿主色、细分隔线、55/45 主工作区。
- 录音为明确标记的本地“演示模式”：点击开始后按固定节奏追加预置中文逐字稿；点击停止后停止计时和追加。
- 逐字稿用原生 `textarea` 编辑；编辑后使纪要标记为“待更新”。
- 生成纪要将当前逐字稿转为会议概览、关键结论、行动项和待确认问题；示例输出应随用户编辑的文本带入内容，而非只显示静态文本。
- 导出功能生成 UTF-8 `.md` Blob，内容对应当前会议主题、逐字稿和纪要。
- 响应式断点下两栏改为单列，键盘可达且状态变化有简洁的屏幕阅读器提示。

## 千问/百炼边界

此 HTML Demo 不直接调用百炼，以避免在浏览器中暴露 `DASHSCOPE_API_KEY`。UI 会标记“演示模式”，并在设置说明中展示正式接入边界：桌面主进程/本地后端通过 Paraformer 实时 WebSocket 转写、通过 `qwen-plus` 生成纪要。正式版将由后端保管 API Key 和 Workspace ID。

## 非目标

- 不采集真实麦克风音频、不发送数据到模型服务。
- 不实现账号、云端存储、多人协作、视频接入或真正的说话人分离。
- 不模拟真实模型输出或暗示演示数据来自千问。

## 交互状态

`idle`：可开始录音，显示初始示例内容；`recording`：计时器递增、预置句段依次写入逐字稿；`stopped`：计时器冻结，用户可以生成纪要或重新开始演示。再次开始应继续展示尚未追加的预置句段，所有操作均保持在当前页面内。

## 视觉与可访问性约束

以 [.superdesign/design-system.md](../../../.superdesign/design-system.md) 为准。所有交互控件使用原生 `button` 或 `textarea`、可见的 `:focus-visible` 样式和中文可访问名称；不使用正 tabindex 或依赖鼠标的交互。状态提示使用 `role="status"`，不逐字播报转写变化。
