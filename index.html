本机服务配置

请自行填写百炼 Base URL 与 API Key。Key 仅发送给当前电脑上的本机服务；页面自身不会将它写入浏览器历史、页面存储或导出文件。

打开后将检查本机配置服务。

保存后，本机服务会将麦克风 PCM 音频转发给 Paraformer，并用所选 Qwen 模型生成结构化纪要。

  • 实时转写：浏览器只连接本机，API Key 由本机服务带入 Paraformer 实时连接。
  • 结构化纪要：逐字稿由本机服务调用已配置的 Qwen 模型，页面只接收验证后的结构化结果。
  • 密钥边界：状态接口不会回传 API Key；重启本机服务后需要重新填写。
